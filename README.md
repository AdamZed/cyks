# Can you keep score?

A webapp for keeping score of 1v1 (solo/team) games

---

## Developing

Install dependencies with bun or npm

```bash
bun install
```

Watch for changes in Tailwind

```bash
bun run tw:watch
```

## Contributing

Check formatting and linting

```bash
bun check
```

...and write

```bash
bun run format
bun run lint:fix
```

Then build

```bash
bun run build
```
